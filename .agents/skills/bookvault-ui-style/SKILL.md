# BookVault UI 样式规范

> 状态：Stage 0 规范稿。M2 桌面端动工时固化为 design tokens（CSS variables）；文中数值是推荐起点，用真实阅读体验校准后回写本文档。

## 1. 设计基调

- **阅读优先**：界面为内容服务，默认克制、低视觉噪音；工具栏类元素自动隐藏，交互时浮现。
- 深浅双主题：跟随系统 + 手动切换。
- 动效只用于操作反馈（翻页、进度、面板进出），不做装饰性动画；尊重系统「减少动态效果」设置。

## 2. Design Tokens（M2 落地为 CSS variables）

- 语义色：`--bg` / `--bg-elevated` / `--fg` / `--fg-muted` / `--accent` / `--danger`。组件禁止硬编码色值。
- 阅读主题独立于 UI 主题，至少 4 档：纸白 / 米黄 / 暗灰 / 纯黑（OLED）。
- 字号阶梯：12 / 14 / 16 / 18 / 20 / 24；阅读器正文字号可调 14–28px。
- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 圆角：卡片 8px、控件 6px；阴影仅用于悬浮层（弹窗、菜单）。

## 3. 中文阅读排版（小说阅读器核心）

- 行高默认 1.7（可调 1.4–2.0）；段落间距 0.5em 或段首缩进 2em（二选一，用户可配置）。
- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`；衬线阅读可选 `Georgia, "Songti SC", "SimSun", serif`。
- 桌面每行 30–42 个汉字，通过栏宽/页边距控制，不靠缩小字号。
- 翻页：平移翻页（默认）+ 滚动模式；键盘（←/→/空格）与鼠标都可用。
- 进度显示：当前章节名 + 百分比；退出自动保存位置（绑定内容哈希，见 dev-standards）。

## 4. 漫画阅读

- 双模式：单页翻页（←/→，预留双页跨页）+ 条漫竖向滚动（Webtoon 模式）。
- 预加载当前页 ±2 张；加载中显示占位与进度条，不白屏。
- 适应模式：适宽 / 适高 / 原始大小，可切换并按书记忆。

## 5. 书架

- 封面网格（3 档密度）+ 列表视图；悬浮显示书名 / 作者 / 阅读进度。
- 封面缺失时用书名首字生成占位封面，背景色由书名哈希决定（同一本书颜色稳定）。
- 私密书架：入口默认隐藏（设置中开启），与普通书架视觉隔离；**私密书名不得出现在窗口标题、系统通知、最近打开列表、任务栏/Dock 预览**（需求 §2.1 硬性要求，实现时必须逐一测试）。

## 6. 可访问性与通用交互

- 所有操作可键盘完成；焦点环不可去除。
- UI 主题正文对比度 ≥ 4.5:1；阅读主题允许用户自行调低（提示即可）。
- 加载 / 错误状态显式呈现（骨架屏或进度提示）；空状态给出引导动作（如「导入第一本书」）。
