## 3. EPUB 分页/竖排适配（未开始，包 A 收尾）

- 现状：EpubReader 为 iframe srcdoc 渲染（ADR-002），仍是滚动模式。
- 做法：iframe 内注入多列 CSS（同 TxtReader 引擎的量测/平移方案），屏数与页码状态跨 iframe 边界上提到 Reader 层；注意 iframe 内键盘不冒泡的历史限制。
- 验收标准：EPUB 分页/竖排/翻页动画与 TXT 行为一致；改排版不重载文档、不丢位置。

## 4. 明确不移植（决策记录，勿反复评估）

- **振动/触觉反馈**：桌面无振动硬件。
- **循环轮播书架**：手机交互形态，桌面 3D 书柜（Book3D）已是更合适形态。
- **edge-tts 在线音色**：云依赖 + 隐私顾虑，用系统 TTS 替代。
- **曲面纸页翻动**：需 canvas/WebGL，成本一顶三；若将来要做放最后，可选。

## 5. 包 A 已交付部分的已知限制（commit `9b61aba`）

- 竖排 + 对页不支持：实测 Chromium/WebView2 的 vertical-rl 多列分片沿纵轴向下堆叠（与 CSS 多列规范不符），竖排分页按实测行为实现（`TxtReader.tsx` 文件头有契约注释）；排版面板在竖排下隐藏「版式」项。若未来引擎改回规范行为需同步调整。
- 滚动模式小说：PgUp/PgDn 保留浏览器默认滚动；阅读中切到「滚动」模式会回到章首（进度已落库，重进书籍可恢复）。
- 自动阅读定时间隔在每次翻页后重新计时（「每页 N 秒」语义）；滚动模式按 `900/autoSec` px/s 匀速滚动。
- EPUB 仍为滚动模式（§3）。
- 交互逻辑已在浏览器 mock 模式实测通过；**Tauri 真窗口（WebView2）未人工验证**。
